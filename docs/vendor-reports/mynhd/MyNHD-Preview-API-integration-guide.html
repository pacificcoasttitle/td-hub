01

Integration flow

  1. Obtain an API secret key and preview access from MyNHD.
  2. Exchange your secret key for an access token.
  3. Request a PDF or image using the property's address or APN.
  4. Check both the HTTP status and the JSON success field.
  5. Decode the returned base64 data and use the returned order_link for the customer's order button.

Examples use illustrative property details. Replace them with a valid property before sending a request.

02

Postman collection

  1. Import preview-api.postman_collection.json into Postman.
  2. Set the collection variable secretKey to your API secret. Leave baseUrl as https://api.mynhd.com unless MyNHD supplies a different server URL.
  3. Set address, city, state, zip, apn, and county for the property you want to look up. county is the five-digit FIPS code.
  4. Send Get access token. Its response script saves the returned token in accessToken for subsequent requests.
  5. Send a PDF or image request by address or APN.
  6. Read pdf_data or image_data and order_link in the JSON response. A successful preview also saves the link in the orderLink collection variable. A multiple-result or failed request clears that variable.

The collection sends the access token as a Bearer token automatically. No separate environment file is needed. Keep variables with these names in the collection so an active environment does not override them. Obtain a fresh token after it expires; automatic reauthentication is not included.

Response checks accept either a successful preview or the HTTP 200 multi_result JSON error. HTTP errors fail the checks. The collection contains no real credentials.

03

Authentication

Send POST /getAuthorizationHeader with the form field secretkey. Authentication does not accept a JSON request body.

cURL / Shell
export MYNHD_SECRET_KEY='YOUR_API_SECRET'

curl --request POST 'https://api.mynhd.com/getAuthorizationHeader' \
  --header 'Accept: application/json' \
  --data-urlencode "secretkey=$MYNHD_SECRET_KEY"

Successful response, HTTP 200:

JSON
{
  "token": "YOUR_ACCESS_TOKEN"
}

The access token expires 24 hours after issue. Include it in every preview request:

HTTP
Authorization: Bearer YOUR_ACCESS_TOKEN

Reuse the token until it expires. If a request returns HTTP 401 with tryReAuth: true, obtain a new token and retry the request. A valid token also requires permission to use the preview endpoints; an account without permission receives HTTP 403.

Keep the secret key on your backend. Direct browser requests from external website origins are currently not allowed by the API's CORS configuration. Call MyNHD from your server, then return the preview result to your frontend.

Both endpoints return application/json. Each request generates one preview format. If you need both formats, send one request to each endpoint and keep each response paired with its own order_link.

Preview requests accept application/json, application/x-www-form-urlencoded, or multipart/form-data. JSON requests should include:

HTTP
Content-Type: application/json
Accept: application/json
Authorization: Bearer YOUR_ACCESS_TOKEN

Request a PDF and save the JSON response:

cURL / Shell
export MYNHD_TOKEN='YOUR_ACCESS_TOKEN'

curl --request POST 'https://api.mynhd.com/report/getMultiFloodFirePreview/pdf' \
  --header "Authorization: Bearer $MYNHD_TOKEN" \
  --header 'Content-Type: application/json' \
  --header 'Accept: application/json' \
  --data '{
    "search": "address",
    "address": "123 Main St",
    "city": "Los Angeles",
    "state": "CA",
    "zip": "90012"
  }' \
  --output preview.json \
  --write-out 'HTTP %{http_code}\n'

The saved file contains JSON. Decode pdf_data to obtain the actual PDF.

05

Successful responses

PDF, HTTP 200:

JSON
{
  "success": true,
  "pdf_data": "<base64-encoded PDF bytes>",
  "order_link": "https://www.mynhd.com/ffprevorder/123/<token>"
}

Image, HTTP 200:

JSON
{
  "success": true,
  "image_data": "<base64-encoded PNG bytes>",
  "order_link": "https://www.mynhd.com/ffprevorder/123/<token>"
}
FieldMeaning
successtrue when a preview was generated.
pdf_dataBase64-encoded PDF bytes; present only for the PDF endpoint.
image_dataBase64-encoded PNG bytes; present only for the image endpoint.
order_linkFull customer order URL associated with this preview.

The data fields contain plain base64, without a data: URL prefix. Decode them once to get the file bytes. The JSON examples above contain placeholders rather than complete files.

06

Complete PHP example

This command-line example works with PHP 5.6 or newer and the cURL extension. Save it as preview-example.php, set MYNHD_SECRET_KEY in your environment, then run php preview-example.php. It authenticates, requests a preview, checks for errors including multiple matches, and saves the decoded file.

PHP
<?php

function postPreviewApi($url, array $fields, $accessToken = null) {
    $headers = array('Accept: application/json');
    if ($accessToken === null) {
        $headers[] = 'Content-Type: application/x-www-form-urlencoded';
        $requestBody = http_build_query($fields);
    } else {
        $headers[] = 'Content-Type: application/json';
        $headers[] = 'Authorization: Bearer ' . $accessToken;
        $requestBody = json_encode($fields);
    }

    $curlHandle = curl_init($url);
    curl_setopt_array($curlHandle, array(
        CURLOPT_POST => true,
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_HTTPHEADER => $headers,
        CURLOPT_POSTFIELDS => $requestBody,
        CURLOPT_CONNECTTIMEOUT => 15,
        CURLOPT_TIMEOUT => 120
    ));
    $responseBody = curl_exec($curlHandle);
    $httpStatus = curl_getinfo($curlHandle, CURLINFO_HTTP_CODE);
    $curlError = curl_error($curlHandle);
    curl_close($curlHandle);

    if ($responseBody === false) {
        throw new Exception('API connection failed: ' . $curlError);
    }
    $response = json_decode($responseBody, true);
    if (!is_array($response)) {
        throw new Exception('API returned invalid JSON (HTTP ' . $httpStatus . ')');
    }
    if ($httpStatus < 200 || $httpStatus >= 300) {
        $message = isset($response['error']) ? $response['error'] : 'API request failed';
        throw new Exception('HTTP ' . $httpStatus . ': ' . $message);
    }

    return $response;
}

$baseUrl = 'https://api.mynhd.com';
$secretKey = getenv('MYNHD_SECRET_KEY');
if (!$secretKey) {
    throw new Exception('Set the MYNHD_SECRET_KEY environment variable first.');
}

$auth = postPreviewApi($baseUrl . '/getAuthorizationHeader', array(
    'secretkey' => $secretKey
));
if (empty($auth['token'])) {
    throw new Exception('Authentication did not return an access token.');
}

$format = 'pdf'; // Change to 'image' for a PNG preview.
$property = array(
    'search' => 'address',
    'address' => '123 Main St',
    'city' => 'Los Angeles',
    'state' => 'CA',
    'zip' => '90012'
);
$preview = postPreviewApi(
    $baseUrl . '/report/getMultiFloodFirePreview/' . $format,
    $property,
    $auth['token']
);

// HTTP 200 can still mean multiple properties were found.
if (!isset($preview['success']) || $preview['success'] !== true) {
    $message = isset($preview['error']) ? $preview['error'] : 'Preview request failed';
    fwrite(STDERR, $message . PHP_EOL);
    exit(1);
}

$dataField = $format === 'pdf' ? 'pdf_data' : 'image_data';
$fileName = $format === 'pdf' ? 'preview.pdf' : 'preview.png';
$fileData = base64_decode($preview[$dataField], true);
if ($fileData === false) {
    throw new Exception('Invalid base64 preview data.');
}
if (file_put_contents($fileName, $fileData) === false) {
    throw new Exception('Could not save the preview file.');
}
echo 'Saved: ' . $fileName . PHP_EOL;
echo 'Order link: ' . $preview['order_link'] . PHP_EOL;

For APN searches, replace the $property block with:

PHP
<?php
$property = array(
    'search' => 'apn',
    'apn' => '123-456-789',
    'county' => '06037',
    'state' => 'CA'
);

The timeout values are client settings for this example, rather than guaranteed API response times. In a production integration, reuse the access token until it expires instead of authenticating before every preview request.

Decode a cURL response in PHP

If you saved preview.json using one of the cURL examples, this PHP script decodes either format:

PHP
<?php
$preview = json_decode(file_get_contents('preview.json'), true);
if (!is_array($preview) || !isset($preview['success']) || $preview['success'] !== true) {
    $message = isset($preview['error']) ? $preview['error'] : 'Preview request failed';
    fwrite(STDERR, $message . PHP_EOL);
    exit(1);
}
$dataField = isset($preview['pdf_data']) ? 'pdf_data' : 'image_data';
$fileName = $dataField === 'pdf_data' ? 'preview.pdf' : 'preview.png';
$fileData = base64_decode($preview[$dataField], true);
if ($fileData === false || file_put_contents($fileName, $fileData) === false) {
    throw new Exception('Could not decode or save the preview.');
}
echo 'Saved: ' . $fileName . PHP_EOL;
echo 'Order link: ' . $preview['order_link'] . PHP_EOL;

Display an image and order button in PHP

After obtaining a successful image response in $preview, render it in your page:

PHP
<?php if (isset($preview['success']) && $preview['success'] === true && isset($preview['image_data'])): ?>
    <img src="data:image/png;base64,<?php echo htmlspecialchars($preview['image_data'], ENT_QUOTES, 'UTF-8'); ?>"
         alt="Property hazard preview">
    <a href="<?php echo htmlspecialchars($preview['order_link'], ENT_QUOTES, 'UTF-8'); ?>"
       target="_blank" rel="noopener">Order report</a>
<?php endif; ?>

For a PDF, decode and serve the bytes with Content-Type: application/pdf. Use the separate order_link for the customer's order button.

07

Multiple-property results

If a lookup finds multiple properties, the API returns HTTP 200 with this JSON error:

JSON
{
  "success": false,
  "code": "multi_result",
  "error": "Preview skipped: multiple properties found for this address."
}

No preview is generated. The response contains no pdf_data, image_data, or order_link. Ask the customer to refine the address or provide a unique APN and county. Do not treat HTTP 200 alone as a successful preview.

08

Other errors

HTTP statusMeaningClient action
400Malformed JSON, missing fields, invalid search, or property/location unavailable.Read error, correct the request or property details, then retry.
401Missing, invalid, or expired credentials/access token.Supply valid credentials or obtain a new token.
403Account lacks endpoint permission.Request preview access from MyNHD.
404Unsupported or unknown endpoint.Check the endpoint path.
500Preview generation or processing failed.Show the error; retry later or contact MyNHD if it persists.

Example HTTP 400 response:

JSON
{
  "error": "Missing required property fields"
}

Example expired/invalid-token response, HTTP 401:

JSON
{
  "error": "JWT Token is wrong.",
  "tryReAuth": true
}

Error responses do not always include success or code. Read error for the message, and consider a preview successful only when the HTTP status is successful and success is exactly true.

09

Existing URL-based preview endpoint

POST /report/getMultiFloodFirePreview is a separate endpoint that accepts form data and returns preview URLs in pdf_url and img_url, with the order link named ffprevorderlink. It does not return pdf_data, image_data, or order_link. Use the /pdf or /image endpoints documented above when you want preview data and its order link together in JSON.
